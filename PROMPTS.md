# AI Prompts Used

## DevConf Hackathon 2026 Section

### Prompt 1 — Section Ideation

I am creating a DevConf 2026 developer conference landing page using
HTML and CSS.

The page already contains a navigation bar, hero section, speakers
section, and pricing section. The assignment requires me to replace
an AI placeholder section with a brand-new section of my own idea.

Suggest a unique and creative section idea that is relevant to a
modern developer conference. Avoid common sections such as FAQ,
Newsletter, or Sponsors.

The section should be simple enough for a beginner to implement
using HTML and CSS and should fit a professional developer
conference website.


### Prompt 2 — Design and Content

I decided to create a "DevConf Hackathon 2026" section.

Design a clean and modern section for a developer conference landing
page.

The section should include:
- A strong heading
- A short description
- Hackathon duration
- Number of participating developers
- Prize pool
- A short call-to-action button

Use a blue, white, and dark navy colour palette to match the existing
DevConf website.

Keep the design professional, simple, modern, and not overcrowded.


### Prompt 3 — HTML and CSS Guidance

Help me implement the DevConf Hackathon 2026 section using simple
HTML and CSS.

I am a beginner learning web development, so keep the structure
easy to understand and explain the purpose of the main HTML elements
and CSS properties.

The section should contain a text area and a statistics area showing
the duration, number of developers, and prize pool.

Make the design visually consistent with a professional developer
conference landing page and use a blue, white, and dark navy colour
palette.
