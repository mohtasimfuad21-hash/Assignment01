# AI Prompts Used

## Placeholder Section

For the placeholder section, I used AI as a learning assistant to help me understand how to create the section using HTML and CSS.

### Prompt Used

"Guide me step by step to create this placeholder section for my DevConf 2026 landing page using HTML and CSS. I want a large box with a light purple background, a purple dashed border, rounded corners, and centered text. The section should contain the heading 'Something Missing?' and the text 'Generate a relevant section with AI'. Give me simple explanations, hints, and examples so I can understand and write the CSS myself."

### How AI Was Used

AI was used to understand:

- How to structure the placeholder section in HTML.
- How to create a large container using CSS.
- How to use a dashed border and border-radius.
- How to center content using Flexbox.
- How to style the heading and paragraph.

The final implementation was written and integrated into the project as part of the overall DevConf 2026 landing page.
